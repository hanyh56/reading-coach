# Reading Coach

一个把“看过一本书”推进到“形成自己的理解并尝试应用”的 AI 阅读教练 Skill。

它不会默认一次生成一篇很长的书籍摘要，而是先建立全书地图，再通过提问、纠偏和现实连接，让你参与学习过程。

## 它解决什么问题

很多阅读工具能告诉你“书里写了什么”，但这不等于你已经理解：

- 收藏了很多书，却不知道先读什么；
- 看过摘要，但讲不清核心观点；
- 读完很快忘记，也不会应用；
- AI 一次输出几千字，最后只剩下“先收藏”。

Reading Coach 的核心区别是：**AI 不替你完成思考，而是帮助你把输入变成自己的判断。**

## v1.0.0 能做什么

| 模式 | 适合场景 | 主要结果 |
| --- | --- | --- |
| 快速模式 | 判断一本书是否值得读、快速建立概览 | 核心问题、关键模型、适用边界、阅读建议 |
| 深度模式（默认） | 真正学会一本书中的重要观点 | 全书地图、逐个概念互动、理解纠偏、现实应用 |
| 复习模式 | 检查是否记住并能迁移使用 | 主动回忆、分层测试、针对性补漏、复习卡 |

所有模式都会遵守事实边界：无法确认书中内容时，AI 应说明不确定，并请你提供目录、版本、章节或原文片段，而不是编造引文和页码。

## 安装

本仓库采用以 `SKILL.md` 为入口的 Agent Skill 结构。将整个仓库放入所用 AI 客户端的 Skills 目录即可；不同客户端的目录和加载方式可能不同。

### Claude Code

```bash
mkdir -p ~/.claude/skills
git clone https://github.com/hanyh56/reading-coach.git ~/.claude/skills/reading-coach
```

### Codex

```bash
mkdir -p ~/.codex/skills
git clone https://github.com/hanyh56/reading-coach.git ~/.codex/skills/reading-coach
```

如果目标目录已经存在，可进入该目录执行 `git pull` 更新。安装后重启或重新加载客户端；如果客户端没有自动触发 Skill，可在提问中明确写出 `reading-coach`。

> 其他支持 Agent Skills 的工具：请按该工具的文档，把本仓库放到其 Skills 搜索目录。是否能自动识别取决于具体客户端，并非本仓库能够单独保证。

## 开始使用

你不需要先准备完整的读书笔记。给出书名和目标即可，例如：

```text
用 reading-coach 带我学习《小岛经济学》。我还没读，想理解储蓄为什么会影响生产能力。
```

```text
用快速模式介绍《思考，快与慢》。重点告诉我哪些观点对日常决策最有用，以及它们的适用边界。
```

```text
我读过《金字塔原理》，请用复习模式检查我是不是真的理解了，不要先给答案。
```

如果 AI 无法可靠获取某本书的内容，请同时提供目录、章节或短片段：

```text
这是我正在读的一段原文。请先问我一个问题，等我回答后再纠偏：
<粘贴短片段>
```

## 深度模式如何工作

```text
确定书籍与目标
      ↓
建立全书地图
      ↓
提出一个预习问题
      ↓
等待你的回答
      ↓
指出成立之处、遗漏和边界
      ↓
连接一个现实场景
      ↓
生成个人认知卡片
```

最重要的一步是“等待你的回答”。如果 AI 在你回答前就把所有答案都讲完，它没有按深度模式执行。

## 设计原则

- 理解优先于信息量。
- 主动回忆优先于重复阅读。
- 用户自己的解释优先于 AI 代写的“标准答案”。
- 事实、解释和个人判断分开表达。
- 行动必须具体，结果必须等待真实观察。

## v1.0.0 的边界

- 不提供书籍全文，也不替代购买或阅读原书。
- 不保证 AI 自动拥有指定版本的可靠内容。
- 不连接外部知识库，不跨书自动建立长期知识图谱。
- 不把医疗、法律、投资等书中观点当作专业建议。
